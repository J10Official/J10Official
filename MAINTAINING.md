# Maintaining this profile

Edit README.md for content. Keep all project descriptions independent; do not imply a pipeline, progression, or shared system between unrelated projects.

The visual identity uses an ink background (#111820), warm white (#F0EDE6), and copper (#E9A76C). The two assets/identity SVGs contain only typeset text and simple rules. The mobile version preserves legibility at narrow widths. No generated illustration, animation, statistics cards, or badge wall is used.

Research entries share the same structure: title, publication/status line, description, source links. Projects each have their own linked heading and description. Education stays visible. The toolkit has a single wrapping icon row followed by plain text.

Native pinned repositories are managed separately in GitHub. Changing pins does not require editing this README. Profile source assets are local to this repository; toolkit icons use Skill Icons and Simple Icons.

When updating claims, verify them against the corresponding public repository or paper. Keep unpublished/private work out of this profile.
